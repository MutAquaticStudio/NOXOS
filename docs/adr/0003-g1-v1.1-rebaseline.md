# ADR 0003: G0.1 / G1 v1.1 architecture amendment

## Status

Accepted for G1 and later gates unless a later, versioned architecture decision supersedes it.
G0 remains frozen and unchanged.

## Amendment

| Previous G1 direction                      | G1 v1.1 direction      |
| ------------------------------------------ | ---------------------- |
| Vercel + Supabase + Cloudflare + Turnstile | Vercel + Supabase only |

Cloudflare, DNS/DNSSEC, Access, custom domains, and Turnstile are legacy or future concerns
outside G1. They are not deployed, reconciled, credentialed, tested, or evidenced by this gate.

## Reason and principle

Cloudflare and Turnstile introduced operational, credential, IAM, provider, and certification
complexity before any product behaviour required them. A provider or security layer may be
introduced only when a measured product or security requirement justifies it.

## Preserved foundation

G1 keeps the React/Vite/TypeScript modular monolith, Module Registry, raw Vercel Functions,
Supabase PostgreSQL via Supavisor transaction pooling, versioned migrations, limited
`nox_app_runtime` and `nox_workflow_runtime` roles, private Supabase Storage,
`WorkflowLauncher` with `@vercel/queue@0.5.1`, ScientificGateway, observability,
accessibility, and the Sydney region strategy (`syd1` plus `ap-southeast-2`).

## Closure evidence

GitHub Actions history is the G1 evidence authority: PR CI, provider-verified Preview for the
PR SHA, and one provider-verified persistent Staging run for its merged main SHA. No evidence
manifest, annotated tag, frozen-document secret mirror, custom domain, or Production action is
required for v1.1.
